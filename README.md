# Private game-tree preview

First-party code: **MIT**. See [LICENSING.md](LICENSING.md) for scope and third-party terms.

Requirements recorded before implementation (Phase 5, 2026-10-04):

- KE-TREE-001: Optional structural tree creation, legal move append, navigation, branch promotion/deletion and exact root-to-move occurrence identity require only chess.js; no account, storage, UI, engine or classifier. Existing application behavior and the full generated widget fingerprint remain unchanged.
- KE-TREE-002: PGN import/export retain nested variations, annotations, custom root FEN and ordered move histories. Export derives move numbers from the root FEN. Structural snapshots contain no application evidence or classification slots.
- KE-TREE-003: One canonical executable structural runtime supplies both module consumers and generated legacy widget compatibility source; generated bytes are checked without changing the approved widget fingerprint. Host evidence/projection operations stay in a compatibility adapter.
- KE-TREE-004: Named tree, PGN and contracts exports, complete source/build instructions and meaningful tests work after packing/installing outside the application on supported Node versions. Runtime dependency: explicitly pinned chess.js 1.4.0.

This is a private preview under the approved MIT license. No public registry publication has been performed.

Named exports:

- `@knights-eye-chess/game-tree/tree`: `createGameStructure`, `appendGameStructureMove`, `gameStructureFromSequence`, primary/path traversal, exact `treeOccurrence`, move-link lookup, promotion/deletion, normalization and detached structural snapshots.
- `@knights-eye-chess/game-tree/pgn`: `parsePgnTree` and `exportPgnTree`.
- `@knights-eye-chess/game-tree/contracts`: structure-only types and `GAME_TREE_VERSION`.

```js
import { parsePgnTree, exportPgnTree } from '@knights-eye-chess/game-tree/pgn';
import { primaryLineEdges, treeOccurrence } from '@knights-eye-chess/game-tree/tree';
const { gameTree, headers } = parsePgnTree('1. e4 e5 (1... c5) *');
const move = primaryLineEdges(gameTree)[1];
console.log(treeOccurrence(gameTree, move.childId)); // root FEN + exact UCI history
console.log(exportPgnTree(gameTree, headers));
```

Package consumers install the private packed archive. Rebuild its included source
independently by extracting the archive into an empty directory and running
`npm ci --ignore-scripts`, `npm run build`, and `npm test`. The shipped
`npm-shrinkwrap.json` pins the source build tools. Runtime installation requires
only chess.js; source builds also use esbuild and TypeScript. Supported Node is
22.13.0 and later. Installation/source-build qualification is recorded in
`QUALIFICATION.json`.

Within this application, `node scripts/build-tree-package.mjs` checks legacy
compatibility staleness before building. `--check-compatibility` checks only;
`--write-compatibility` is the deliberate regeneration command. The canonical
structural JS declarations generate unchanged widget functions in their original
order. App-only append fields and evidence callbacks are injected by the separate
host compatibility transform specification; the structural package contains none
of those fields or callbacks. The complete widget document fingerprint stays at
its existing approved value. Existing server link-ID allocation and explicit-ID
options are preserved by the typed structural adapter.

Promotion sets one primary-child pointer. Deleting a primary edge chooses the
next sibling, then the previous sibling, and removes the deleted subtree. The
root FEN and full ordered UCI path identify an occurrence; equal/transposed FENs
and repeated board positions never merge distinct histories. Supplied annotations
remain attached to edges. Structural snapshots whitelist those fields and detach
arrays. App-specific transient-branch exclusion and completed analysis storage
remain host responsibilities.

Limits: this preserves the existing chess.js-backed parser, not a comprehensive
PGN standard implementation. Root/pre-move comments, root NAGs and arbitrary
unknown PGN extensions are not represented; unheaded movetext result markers do
not become metadata. Export defaults to `headers.Result` or `*`; callers can
supply an explicit result. It exports legal structural variations, attached
symbolic annotations, numeric NAGs and move comments. The historical move-comment
formatter replaces a closing brace with `]`. Plain structural snapshots ignore
unknown host extensions but retain structural edges even when a host marks them
transient. The app's existing PGN formatter is unchanged. There is no engine,
opening database, result inference, classification, persistence, account or UI
integration in this package.

## Standalone repository build

Use Node 24 or newer. From a clean checkout:

```sh
npm ci
npm run check
npm run pack:checked
```

The source snapshot is recorded in `SOURCE-ORIGIN.json`. This private preview
uses version `0.1.0-dev.2`; earlier `0.1.0-dev.1` artifacts remain immutable.
Internal dependencies are pinned archives in `vendor/npm`. Update an existing
dependency with `node scripts/update-dependency.mjs @knights-eye-chess/name
/absolute/path/package.tgz`, then run `npm ci` and `npm run check`. Review the
manifest, lockfile, archive hash and tests together before committing.
No registry, automatic CI or website deployment is required for these commands.

`pack:artifact` packs a temporary copy and records exact package versions for
sibling dependencies. Use it instead of bare `npm pack`; repository-local file
pins belong to the source build and are not published as consumer dependencies.
